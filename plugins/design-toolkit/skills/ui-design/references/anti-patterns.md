# 反模式清单：可识别的「AI 味」

判定原则：一个视觉手法若放在任何产品上都成立，它就没有承载信息，属于模板味。本清单收录高频出现的通用套路；命中任意一条都应先问「这里的信息是什么」，答不出就替换。清单是默认禁用而非绝对禁令：用户或品牌系统明确要求时照做，但不要把免费创意额度继续花在清单内套路的变体上。

## 配色

- 奶油或米白底（近 `#F4F1EA`）+ 高对比衬线标题 + 赤陶/暖陶色强调（常见值就在 `#D97757` 附近——那是 Anthropic 自家 Claude 交互强调色，出现在用户的 brief 上即穿帮）：官方原文点名的第一种默认审美。替代：从产品所在行业的视觉词汇取色，或改用非暖色中性底。
- 近黑深色底 + 单一亮酸绿或朱红强调：原文点名的第二种默认审美。替代：深色界面用低饱和强调色，或把强色只留给唯一 CTA。
- 紫蓝渐变 hero、渐变球、光晕装饰：把「科技感」外包给渐变。替代：渐变仅在品牌系统已有或用户明确要求时使用，且只用于一个元素。
- 每个板块换一种强调色：颜色不再标记任何东西。替代：强调色唯一，只标记可交互元素与关键信息。

## 布局

- 居中 hero（大标题 + 副标题 + 渐变主按钮）+ 三列图标卡片 + 底部 CTA 的「落地页模板」。替代：从内容主次重排——首屏直接给产品证据（截图、数据、交互），不喊口号。
- 圆角卡片 + 左侧彩色竖条：信息没有被分组，只是被装饰。替代：用留白与对齐分组；彩色条只在表达状态（新、警示）时保留。
- 报纸式多栏排版：极细分隔线 + 零圆角 + 密集栏：原文点名的第三种默认审美。替代：分组用留白，栏宽服从行长约束。
- 圆角卡片套件：内容切成同款圆角卡片、无视层级统一圆角、每张卡压同一个软灰阴影（`rgba(0,0,0,.1)`）、渐变当装饰；「圆角卡 + 左侧彩色竖条」同属此类。替代：用留白与对齐分组；层级差异应体现在圆角与阴影档位上，而不是处处同款。
- 模板铬件（与主题无关却总会出现的零碎）：标题上方加宽字距的全大写眉标、middle-dot 元信息串（`作者 · 日期 · 分类`）、`WORD — 片段` 式带间隔长破折号的标签、以近黑灰（`#0B0B0B`、`#111`）冒充纯黑、小号数据标签用等宽字体、链接与按钮文字尾部追加 `→`。替代：逐个质询能否删除或改写为承载信息的形式。
- 头像堆叠 + 「加入 10,000+ 开发者」：社交证明占位符。替代：用真实可核验的证据，没有就不放。

## 排版

- 标题里挑一个词换强调色或斜体：装饰不承载信息。替代：层级靠字号与字重。
- 全大写 + 加宽字距的小标签（`F E A T U R E S`）：机械感。替代：普通字号小标题或真实序号。
- 字号超过 6 档、或正文小于 15px：层级失控。替代：收敛到 token 阶梯。
- 正文行长超过 80 字符仍通栏：可读性下降。替代：限制正文容器宽度。

## 装饰与动效

- 每个板块入场都 fade + slide-up：非用户触发的动效应是全页一次的编排，逐节入场是最强识别符。替代：入场只做一次，或交给滚动触发并支持降级。
- 所有元素都有 hover 效果（上浮 + 阴影加深）：反馈通胀。替代：hover 反馈只给可交互元素。
- emoji 当列表符或图标：视觉噪音且风格不可控。替代：图标库或纯排版；专业语境一律不用 emoji。
- 玻璃拟态（半透明 + 模糊 + 高光描边）铺满全站：可读性与性能双输。替代：至多一个元素使用，或改为实色分层。

## 文案

- 「赋能」「一站式」「极致体验」式空话口号。替代：写具体动词与可核验数字。
- 装饰性说明段（用户不会读的「欢迎来到……」）。替代：删。
- 错误信息道歉体（「抱歉，出错了」）。替代：指向行动（「文件超过 10MB，压缩后重试」）。

## 配套检查

自评时逐条扫过：命中的条目要么替换为承载信息的做法，要么写明保留理由（用户要求、品牌系统既有）。写不出保留理由即回炉。
