# 设计 token 与排版规则

token 是风格的最小事实来源：写组件代码前先定 token，写码时只用 token，改风格只改 token。本文件给出最小 token 集模板、排版规则与自查清单。

## 最小 token 集

一页写完，先于任何组件代码：

```text
颜色（4–6 个命名色起步，命名表达用途不表达外观）
  bg-surface      页面底色（例 #FAFAF8）
  bg-raised       卡片/浮层底色（例 #FFFFFF）
  text-primary    主文字（例 #1A1A1A）
  text-secondary  次文字/元信息（例 #6B6B6B）
  accent          唯一强调色，标记可交互与关键信息（例 #2E5AAC）
  border-subtle   分隔线/描边（例 #E5E5E0）
  [按需] success / warning / danger 状态色

字体（至多两款，两款时需明显区分）
  font-body       正文字族
  font-display    标题字族（可与正文同款）

字号阶梯（5–6 档，比例约 1.2–1.25，或沿用项目既有体系）
  12 / 14 / 16 / 20 / 24 / 32（px，随根字号换算）

间距：统一基数 4 或 8，常用 4/8/12/16/24/32/48/64
圆角：至多两档（如 6px 控件、12px 卡片）
阴影：至多两档（如悬浮层、弹层），能不用则不用
```

规则：

- 先定中性色阶（底色、文字、边线），再放唯一强调色；强调色只标记可交互元素与关键信息，不做装饰。
- 状态色（成功/警告/危险）独立命名，不复用强调色的变体。
- 暗色模式如适用，在同一用途名下定义第二套值（`bg-surface` 的暗色值），不做简单反色——阴影换边线、图片降亮度。

## 排版规则

- 至多两款字体：正文与标题可共用一款，用两款时须明显区分；不要为单个页面引入第三款。
- 字号不超过 6 档；层级靠字号、字重与留白表达，不靠颜色数量与全大写。
- 正文行长 ≤ 80 字符（衬线正文可略放宽，但仍须设上限）；标题行长显著短于正文。
- 正文行高 1.5–1.7，标题行高 1.1–1.3；段落间距大于行内行距，让分组可见。
- 表格与数据列用等宽数字（`font-variant-numeric: tabular-nums`）对齐。
- 中西文混排注意标点与间距处理，用排版方案解决，不手敲空格。

## ASCII 线框

关键页面动手前先画线框，把主次与区块从代码里拿出来先审：

```text
┌──────────────────────────────────────┐
│ nav：logo · 3 个链接 · [主 CTA]      │
├──────────────────────────────────────┤
│ hero：一句话主张（唯一记忆点）        │
│       次说明 · [主按钮] [次按钮]     │
├───────────────┬──────────────────────┤
│ 产品截图（大） │ 三条要点（小，安静） │
├───────────────┴──────────────────────┤
│ footer：元信息一行                    │
└──────────────────────────────────────┘
```

线框审三件事：视线落点是否唯一；区块主次是否与页面首要目标一致；有没有既不主也不次的板块（删）。

## 自查清单

- [ ] 颜色、字号、间距、圆角全部来自 token，代码无魔法值；
- [ ] 强调色唯一，只用于可交互与关键信息；
- [ ] 字体 ≤ 2 款、字号 ≤ 6 档、正文行长有上限；
- [ ] 间距来自统一基数，组间距大于组内距；
- [ ] 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1；
- [ ] 暗色模式（如适用）为双套 token，非简单反色。
