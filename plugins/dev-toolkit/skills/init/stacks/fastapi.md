## FastAPI 专项规范

### 模块与依赖边界

- 路由、schemas、services、models 分层分文件；一个资源一个 router 文件。
- 路由函数保持薄，业务逻辑在 service 层；禁止路由直连数据库。

### 类型、数据与接口契约

- Pydantic 模型按领域归文件；请求与响应模型分开定义，不复用 ORM 对象直接出参。
- 路径参数、依赖注入显式声明类型。
- 接口契约写进 Pydantic 模型与 OpenAPI 元数据，不用普通注释代替。
- API 结构变更视为破坏性契约变化，同步更新文档与调用方。

### 状态、并发与资源生命周期

- 异步路径禁止同步阻塞调用，用异步库或线程池隔离。
- 数据库会话由依赖注入管理生命周期，请求结束即释放，禁止跨请求持有会话。
- 后台任务写明取消与超时语义，禁止无界排队。

### 错误、安全与可观测性

- HTTPException 携带可定位的 detail；全局异常处理器统一兜底并记日志。
- 禁止 except 后返回 200 加空体；错误日志带 request id 与关键参数。

### 测试与可判定验收

- pytest + TestClient 覆盖接口行为；行为变化配套接口测试。

### 反模式与替代方案

- 禁止在依赖注入里夹带隐式全局状态，改为显式参数或配置对象。
